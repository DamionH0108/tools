把浏览器接入固定出口

红框标的是操作位置。截图中的 SOCKS5、7901 和示例 IP 不要照抄。本工具生成的是 HTTP · 127.0.0.1:以面板为准，账号密码留空。仅用于同一台 Mac 上的 MoreLogin。

01　新建或编辑浏览器环境

点右上角 New profile。已有分配好的环境，可以直接编辑。

02　找到自有代理设置

选择 Browser → Advanced create → New proxy。Proxy type 与 Clash 监听协议一致；IP query channel 是查询渠道，不是代理协议。

03　填写主机和端口

Proxy server 左侧填 127.0.0.1，右侧填工具显示的专用端口。图中的 7901 只是示例。

04　配置完成，测一次代理

在 MoreLogin 点 proxy detection。必须实际出现 Check passed，且 Egress IP 等于分配给你的固定 IP，才保存。若失败，检查监听端口、协议和 Clash。

05　启动后，再测浏览器实际出口

Running 仅表示环境已启动。在工具里点「完成配置 · 检测浏览器出口」，把检测页粘贴到刚启动的浏览器地址栏运行。出口一致后再登录 Google。
